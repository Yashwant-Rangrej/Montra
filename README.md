# Montra

Montra is a comprehensive, beautifully designed personal finance and budget management application built with Flutter. It helps you track your expenses, manage your budgets, and gain detailed insights into your financial habits—all from a clean and intuitive user interface.

## 🚀 Key Features

*   **Expense & Income Tracking:** Easily log your daily transactions (expenses and income). Categorize them to see exactly where your money is going.
*   **Budget Management:** Set monthly or custom budgets for different categories. Get alerts when you are nearing your limits and monitor your spending visually.
*   **Financial Analytics:** View detailed, interactive charts and insights into your spending patterns over time.
*   **Custom Categories:** Create and manage custom categories for your transactions to tailor the app to your specific lifestyle.
*   **Secure & Private:** Your financial data is securely stored, ensuring your privacy is always maintained.

## 🚦 Getting Started

Follow these steps to run Montra locally on your machine.

### Prerequisites

*   [Flutter SDK](https://docs.flutter.dev/get-started/install) installed on your machine.
*   An IDE like Android Studio, VS Code, or IntelliJ IDEA.
*   An Android or iOS emulator, or a physical device connected.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/montra.git
    cd montra
    ```

2.  **Get dependencies:**
    ```bash
    flutter pub get
    ```

3.  **Run the application:**
    ```bash
    flutter run
    ```
